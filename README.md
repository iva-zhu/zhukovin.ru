# zhukovin.ru

Личный сайт Ивана Жуковина — звукорежиссёра, продюсера и музыканта из
Владивостока. Блог, заметки и небольшие инструменты.

<https://zhukovin.ru>

## Зачем это здесь

Сайт — обычный статический HTML, собранный [Hugo](https://gohugo.io/).
Никаких аналитик, счётчиков, cookie-баннеров и внешних JS-скриптов: страницы
не делают сетевых запросов к третьим сторонам и открываются почти мгновенно.
CSS — один файл, картинки — статикой, скриптов на страницах нет вообще.

Репозиторий открыт, чтобы было видно, как всё устроено: шаблоны, стили,
сборка и деплой.

## Структура

```
content/     посты и страницы (Markdown)
layouts/     переопределения шаблонов
assets/      исходники стилей (main.scss, css/)
static/      статика: картинки, style.css, модуль /bpm
themes/      тема zhukovin (форк lugo Люка Смита)
hugo.toml    конфигурация сайта
deploy.sh    сборка и заливка на сервер
```

Модуль **BPM → ms / Compressor** живёт отдельно:
<https://github.com/iva-zhu/bpm-tool>, при деплое копируется в `static/bpm/`.

## Локальный запуск

```sh
hugo server -D      # http://localhost:1313
hugo                # сборка в public/
```

Нужен Hugo extended (для SCSS).

## Деплой

`./deploy.sh` синхронизирует калькулятор из соседнего репозитория, собирает
сайт и заливает `public/` на сервер через `rsync`. Адрес сервера и путь
заданы в скрипте — поменяйте их под себя.
